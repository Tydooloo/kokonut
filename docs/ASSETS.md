# Website assets

The coconut brand mark is an original editable SVG in `dist/favicon.svg`, retained in the navigation and favicon. Kokonut uses a capital K.

The SideQuest photographs were copied from its existing public app assets. Their original URLs are recorded in that app's `docs/COMMAND_HISTORY.md`:

- Coast: https://images.unsplash.com/photo-1518837695005-2083093ee35b
- Camping: https://images.unsplash.com/photo-1504280390367-361c6d9f38f4

DM Sans and Manrope are served locally as Latin variable WOFF2 fonts. Their SIL Open Font Licenses are included in `docs/licenses/`.

Phone displays are labelled illustrative interfaces. The current textures are original rasterized UI compositions, not screenshots of the distributed APKs.

The redesigned site's four product sculptures, animations and studio renders were created in Blender 4.5.9. The editable scene is `art/kokonut-collection.blend`, with a reproducible generator in `art/build_scene.py`. Each runtime GLB embeds textures and a six-second animation. Tiny WebP posters provide artwork without WebGL. The VST Pedal is a concept visualisation, not a photographed or working product.

Three.js 0.180.0 is vendored under `dist/vendor/three/`, together with its MIT license. The runtime does not request external models, fonts or scripts. See `docs/REDESIGN.md` for the complete asset pipeline.

The earlier central wordmark, now unused in the live website, is original Blender geometry, generated by `art/build_wordmark.py` and saved in `art/kokonut-wordmark.blend`. Its lime face, olive extrusion and bevel are separate editable materials. `dist/assets/3d/kokonut.glb` is the runtime export. `art/fonts/dm-sans-wordmark.ttf` is a weight-850 static instance of the existing DM Sans variable font, generated using FontTools; the source font's SIL license is in `docs/licenses/`. The orbit's rounded cards, printing and contact shadows are generated locally in Three.js. No WDCC artwork or code was copied.

The current carousel centre uses the original coconut SVG from `dist/favicon.svg`. It is rasterized locally at 512px for a transparent WebGL texture, preserving the original artwork. The four animated Blender product models remain active.
