# Interactive portfolio redesign

Source: `https://github.com/Tydooloo/kokonut`, downloaded to the local Kokonut workspace. Work is on `redesign/interactive-collection`, based on `a3d722c`.

## Direction

An independent studio collection centred on a single automatically moving 3D orbit. Four cards carry floating product sculptures around the original coconut icon. One enlarged card holds focus, then a short animated transition advances the next product. WDCC's actual orbital section was reviewed as a motion reference; its artwork and source were not copied. The surrounding page uses restrained typography, compact controls and first-person About me copy. Existing Kokonut identity, app icons and public Android release metadata are retained.

The four projects are SideQuest, Haste, Revisen and a **concept** for a guitar pedal that hosts Windows VST plug-ins for live performance. The pedal page explicitly says there is no prototype or download yet. Its rendered knobs, layout and display are design studies, not product specifications.

## Source assets

- Blender 4.5.9 generated all four meshes, studio renders and animation loops through `art/build_scene.py`.
- `art/kokonut-collection.blend` is the editable source, including packed textures, named materials, lighting, camera and collection animation actions.
- `art/kokonut-wordmark.blend` is retained as an unused earlier design study. The live centre uses `dist/favicon.svg`.
- `art/textures/` holds original illustrative UI art generated by `scripts/make-screen-textures.py`. The SideQuest texture reuses the repository's existing camping photograph.
- Each GLB embeds its own texture and animation. WebP fallbacks are generated from Blender PNG renders with `scripts/optimize-renders.py`.
- Three.js 0.180.0 is served locally with its MIT license. No external font, model or animation service is required at runtime.

## Content and behavior

- Four cards move through actual 3D depth. Their Blender loops, more pronounced floating motion and the original coconut icon share one scene.
- Each product holds focus for 3.8 seconds, then a 0.82-second transition advances the next card. Dragging and keyboard controls still select products. Wheel input scrolls the document only. The compact pause button freezes automatic rotation while the models keep floating. The former controls strip and product index are removed.
- Dedicated app pages with Android download panels, accurate file sizes and existing setup requirements.
- A dedicated pedal concept page, studio introduction, download directory, privacy page and 404 page.
- Responsive layout, real anchor links, visible keyboard focus, reduced-motion support, pause controls and static artwork fallbacks.
- The production CSP permits local blob textures required by embedded GLB images. Local preview applies the same policy.
- Existing APK URLs, checksums and release records are unchanged. No app backend or account configuration is modified.
