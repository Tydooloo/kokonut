# Android test builds · 17 September 2026

Download the APK for your app, open it on an Android phone or tablet, and follow the Android installer. Minimum Android version: **7.0 (API 24)**. All builds include ARM64, ARMv7 and x86-64 architectures.

- **SideQuest 1.0.0:** hosted Firebase/Supabase configuration; internet and account required. Live services and account flows were not retested for this website release.
- **Macrova 0.1.0:** local manual food logging. AI and USDA require a configured Macrova server; account features require Firebase. No public backend is supplied by this download.
- **Revisen 0.1.0:** requires a reachable Revisen server. Ask your test organiser for its URL and use Connection settings. Installation alone does not enable the learning workspace.

These are debug-signed development builds for testing, not store releases. No iOS download is included. Back up local data before removing or replacing older test installations. Keep Android Play Protect enabled.

All APK signatures were verified with Android apksigner. See `manifest.json` for exact sizes and SHA-256 checksums. The website provides installation help at https://kokonut.cc/#install.
